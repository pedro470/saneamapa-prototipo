# Skills e Competências Técnicas Utilizadas — SaneaMapa

Este documento registra as competências técnicas, padrões de engenharia e práticas aplicadas na concepção e implementação do sistema **SaneaMapa**.

| Área / Skill | Aplicação no Projeto | Referências no Repositório |
|---|---|---|
| **Programação Orientada a Objetos (Java 21)** | Modelagem de domínio rico aplicando os 4 pilares: abstração (`EntidadeAuditavel`, `Evidencia`, `GeometriaCamada`), encapsulamento (máquina de estados de `Ponto`, regras LGPD em `Relato`, bloqueio em `Usuario`), herança (`EvidenciaFoto`/`Video`/`Audio`, `SaneaMapaException`) e polimorfismo (tratamento de evidências, geometria espacial e estratégia de pontuação). | [domain/model/](../saneamapa-app/src/main/java/br/edu/cesmac/saneamapa/domain/model), [DominioPooTest.java](../saneamapa-app/src/test/java/br/edu/cesmac/saneamapa/DominioPooTest.java) |
| **Spring Boot 3 & API REST** | Estruturação em camadas (`controller`, `service`, `repository`, `dto` com Java Records), validação declarativa (`jakarta.validation`), upload multipart e tratamento global de exceções padronizado (`RNF03`). | [controller/](../saneamapa-app/src/main/java/br/edu/cesmac/saneamapa/controller), [GlobalExceptionHandler.java](../saneamapa-app/src/main/java/br/edu/cesmac/saneamapa/controller/GlobalExceptionHandler.java) |
| **Spring Security & JWT (Stateless)** | Autenticação stateless com tokens JWT (`jjwt`), criptografia de senhas com BCrypt, bloqueio por força bruta (5 tentativas / 15 min) e controle de acesso baseado em perfis (RBAC: `FISCAL`, `PREFEITURA`, público LGPD). | [security/](../saneamapa-app/src/main/java/br/edu/cesmac/saneamapa/security) |
| **Persistência ORM (Hibernate / Spring Data JPA)** | Mapeamento objeto-relacional incluindo herança `SINGLE_TABLE`, `@MappedSuperclass`, consultas JPQL/derivadas e controle transacional (`@Transactional`). | [repository/](../saneamapa-app/src/main/java/br/edu/cesmac/saneamapa/repository), [service/](../saneamapa-app/src/main/java/br/edu/cesmac/saneamapa/service) |
| **Banco de Dados PostgreSQL (DDL, Triggers, Views, Índices e RBAC)** | Modelagem de 11 tabelas aplicando as **4 integridades** (Entidade, Domínio, Referencial e Semântica), criação de 3 triggers PL/pgSQL, 7 índices (compostos e parciais), 3 roles/usuários com privilégio mínimo por coluna e 4 views analíticas/LGPD. | [database/](../saneamapa-app/database) |
| **Geoprocessamento e Mapas Web** | Cálculo de distância geodésica (fórmula de Haversine para agrupamento de 50 m e raio de vistoria de 100 m), algoritmo *Ray-Casting* para verificação de ponto em polígono e visualização interativa com Leaflet / OpenStreetMap. | [GeoUtils.java](../saneamapa-app/src/main/java/br/edu/cesmac/saneamapa/domain/service/GeoUtils.java), [mapa-saneamapa.js](../saneamapa-app/src/main/resources/static/js/mapa-saneamapa.js) |
| **Privacy by Design / Conformidade LGPD** | Ocultação de coordenadas exatas, contatos e áudios na API/mapa público, proteção de acesso às mídias, identificação obrigatória com nome e telefone visíveis só à equipe interna, restrição de camada epidemiológica a polígono e auditoria imutável (`append-only`). | [LogAuditoria.java](../saneamapa-app/src/main/java/br/edu/cesmac/saneamapa/domain/model/LogAuditoria.java), [MoradorController.java](../saneamapa-app/src/main/java/br/edu/cesmac/saneamapa/controller/MoradorController.java) |
| **Testes Automatizados (JUnit 5 & MockMvc)** | Testes unitários de domínio OO e testes de integração ponta a ponta com banco H2 em memória validando fluxos completos, RBAC e importação de Censo. | [src/test/](../saneamapa-app/src/test/java/br/edu/cesmac/saneamapa) |
| **Containerização (Docker & Docker Compose)** | Build multi-stage Maven/Temurin 21 e orquestração com PostgreSQL 16 e inicialização automática dos scripts SQL. | [Dockerfile](../saneamapa-app/Dockerfile), [docker-compose.yml](../docker-compose.yml) |
| **Assistência por IA (Desenvolvimento Apoiado)** | Uso de modelos de IA (Gemini) para apoio na prototipação, estruturação dos scripts SQL e documentação de requisitos/arquitetura, conforme registrado na entrega 3AF. | [ENTREGA_3AF_SQL.md](../saneamapa-app/database/ENTREGA_3AF_SQL.md) |
